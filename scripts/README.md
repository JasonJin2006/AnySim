# Scripts Directory

`scripts/` 用于放开发过程中的手工脚本，而不是正式测试。

分类约定：
- `scripts/debug/`：定位问题、检查运行时状态、验证编译细节的调试脚本
- `scripts/demo/`：手工演示或端到端试跑脚本
- `scripts/tools/`：辅助工具脚本

放在 `scripts/` 的脚本通常具有这些特点：
- 依赖人工查看输出
- 不一定有稳定断言
- 不适合直接作为 CI 质量门槛
- 可以临时或阶段性存在

正式自动化测试应放在 `test/`：
- 需要明确断言
- 可以重复运行
- 失败代表回归
- 应作为项目质量门槛
